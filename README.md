# Portfólio de produtos

Site estático (um único `index.html`, sem build) para publicar no GitHub Pages.

## Publicar em rafaeladolfocouto.github.io

1. Crie um repositório público chamado `rafaeladolfocouto.github.io`.
2. Envie `index.html` e `.nojekyll` para a branch `main`.
3. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
4. Em um ou dois minutos o site fica em https://rafaeladolfocouto.github.io

Para usar um repositório com outro nome (por exemplo `portfolio`), o endereço vira https://rafaeladolfocouto.github.io/portfolio

## Editar

Cada produto é uma seção `<section class="prod" id="...">` com as cores definidas no bloco "temas por produto" do CSS. Os logos e as telas são carregados direto dos sites de cada produto.
